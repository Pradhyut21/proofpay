## Reproduce the sample recording

1. Run the app and reset the sample workspace. A real PayPal invoice cannot be discarded by resetting the demo.
2. Use the UI synthetic completion fixture, also documented in [Seed evidence](SEED_EVIDENCE.md).
3. Capture actual interactions and keep sample badges readable. Keep review tokens, secrets, notifications and personal browser information out of public footage.
4. Use the cue table as the edit plan. Verify the final export, captions and measured duration before uploading.

## If recording configured integrations later

Record the actual model shown by the UI and the same sandbox invoice through creation, payment-page testing and reconciled status. Record those checks in `VALIDATION.md`.
