# Submission checklist

Requirements checked against the [Devpost overview](https://paypalaihackathon.devpost.com/) and [Official Rules, sections 1, 3 and 4](https://paypalaihackathon.devpost.com/rules) on **17 October 2026**. Recheck the live rules before submitting.

The deadline is **13 November 2026, 01:30 IST** (12 November, noon PST). Judges' access must remain available through the judging period ending **15 December 2026, 21:30 IST**. The entrant must confirm eligibility, ownership, third-party permissions and any team representative authority.

No repository URL, public deployment, model run, sandbox payment or YouTube upload is assumed complete by this checklist. Mark a row complete only with evidence in `VALIDATION.md`.

## Finish in this order

1. Finish application checks and fill in the validation record.
2. Configure the AI and sandbox credentials privately; complete the sandbox test in `SETUP.md`.
3. Publish the complete source repository and verify the MIT license is detected.
4. Record the functioning application; make its sample/live state explicit.
5. Export a video shorter than three minutes, inspect it, and upload it as **Public** on YouTube.
6. Fill Devpost using `DEVPOST.md`, verify every link in a signed-out browser and submit before the deadline.

Keep secret API credentials outside the public repository. If judging needs special access, provide a controlled test account or appropriate private testing instructions rather than publishing reusable secrets.
